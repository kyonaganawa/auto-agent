## Content Generation Prompts

### Game Review Prompt

```
Write a comprehensive, SEO-optimized review of [GAME_NAME] for gamers considering a purchase.

TARGET AUDIENCE: Gamers aged 18-35 researching whether to buy this game
TONE: Informative, balanced, slightly conversational
LENGTH: 2,000-2,500 words
SEO KEYWORDS: [GAME_NAME] review, is [GAME_NAME] worth it, [GAME_NAME] gameplay

STRUCTURE:
1. Introduction (150-200 words) - Hook the reader, state verdict upfront
2. Game Overview (200 words) - What is it, who made it, basic premise
3. Gameplay Analysis (500-600 words) - Deep dive into mechanics, what works and doesn't
4. Graphics & Sound (300-400 words) - Visual and audio analysis
5. Story & Characters (300-400 words) - If applicable
6. Performance & Technical (200-300 words) - Bugs, optimization, accessibility
7. Value & Replayability (200-300 words) - Price point, hours of content
8. Pros & Cons (bullet points)
9. Final Verdict (200 words) - Overall recommendation with rating X/10

REQUIREMENTS:
- Be honest and balanced - acknowledge both strengths and weaknesses
- Include specific examples from gameplay
- Provide value to readers (help them make a decision)
- Use natural keyword integration
- Include comparisons to similar games
- End with clear recommendation (buy/wait/skip)

AVOID:
- Generic statements that could apply to any game
- Spoilers without warning
- Excessive technical jargon
- Bias without justification
```

### Game Guide Prompt

```
Create a comprehensive gameplay guide for [GAME_NAME] targeting both beginners and experienced players.

TARGET AUDIENCE: Players who want to improve or master the game
TONE: Helpful, encouraging, expert
LENGTH: 2,500-3,000 words
SEO KEYWORDS: [GAME_NAME] guide, [GAME_NAME] tips, how to play [GAME_NAME]

STRUCTURE:
1. Introduction - What this guide covers
2. Getting Started (400-500 words) - First steps, early game tips
3. Beginner Tips (600-700 words) - Essential knowledge for new players
4. Advanced Strategies (700-800 words) - Pro techniques and tactics
5. Character Builds/Loadouts (400-500 words) - Optimized setups
6. Secrets & Hidden Content (300-400 words) - Easter eggs, hidden items
7. Common Mistakes (300-400 words) - What to avoid
8. Progression Guide (400-500 words) - Early/mid/late game priorities
9. FAQs (5-7 questions)

REQUIREMENTS:
- Provide actionable, specific advice
- Use clear, step-by-step instructions where applicable
- Include multiple strategies for different playstyles
- Organize information logically
- Use bullet points and headers for scannability
- Be comprehensive but concise

FOCUS ON:
- Practical tips that make immediate difference
- Solutions to common frustrations
- Time-saving strategies
- Hidden mechanics or non-obvious tips
```

### Top 10 List Prompt

```
Create an engaging "Top 10 [CATEGORY] Games" listicle for [YEAR].

TARGET AUDIENCE: Gamers looking for recommendations in this category
TONE: Enthusiastic, authoritative, engaging
LENGTH: 2,000-2,500 words (200-250 per game)
SEO KEYWORDS: best [CATEGORY] games [YEAR], top [CATEGORY] games

STRUCTURE:
1. Introduction (150-200 words) - Why this category is great, what readers will find
2. Games #10-#4 (200-250 words each) - Shorter descriptions
3. Games #3-#1 (250-300 words each) - More detailed, these are the standouts
4. Honorable Mentions (100 words total)
5. How We Ranked (100-150 words) - Methodology
6. Buying Guide (150 words) - Where to find deals
7. FAQs (3-5 questions)

FOR EACH GAME INCLUDE:
- Title, developer, platforms, price
- What makes it special
- Key features (bullet points)
- Who it's perfect for
- Rating X/10
- Buy link

REQUIREMENTS:
- Mix of well-known and hidden gems
- Variety in gameplay styles
- Honest assessments
- Clear ranking justification
- Enthusiasm without overselling

RANKING CRITERIA:
- Gameplay quality (40%)
- Value for money (20%)
- Innovation (15%)
- Polish/presentation (15%)
- Community reception (10%)
```

## SEO Checklist

For every article:

- [ ] Target keyword in title (front-loaded)
- [ ] Target keyword in first 100 words
- [ ] Target keyword in at least one H2
- [ ] Meta description 150-160 characters
- [ ] URL slug includes keyword
- [ ] Alt text on all images
- [ ] Internal links (3-5 per article)
- [ ] External links to authoritative sources
- [ ] Natural keyword density (0.5-1.5%)
- [ ] Readability grade 6-8
- [ ] Content length 2,000+ words
- [ ] Proper heading hierarchy (H1 → H2 → H3)
- [ ] Engaging introduction
- [ ] Clear conclusion
- [ ] FAQ section
- [ ] Related articles links
- [ ] Schema markup (Review/Article)
- [ ] Social sharing meta tags
